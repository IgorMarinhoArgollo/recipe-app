Aplicativo de receitas de comidas e bebidas, feito com **React** e pensado primeiro para celular. Ele consome duas APIs públicas de receitas (TheMealDB e TheCocktailDB) e foi desenvolvido em equipe para praticar **metodologias ágeis (Scrum)** e **pair programming**.

**🔗 Demonstração: [project-recipe-app.netlify.app](https://project-recipe-app.netlify.app/)**

Para entrar, use `email@email.com` como e-mail e `1234567` como senha.

![Demonstração](./public/demonstracao.gif)

## Sobre o projeto

Desenvolvido no módulo de Frontend da Trybe, com quatro colegas, para praticar a transferência de dados por props, a Context API e React Hooks. O layout é pensado primeiro para telas pequenas (320x640px) e pode ser estendido para telas maiores.

## Funcionalidades

- Navegação e busca de comidas e bebidas, com filtros por categoria
- Exploração de receitas por ingrediente e por área
- Detalhes da receita e receitas em andamento
- Perfil com receitas favoritas e receitas feitas
- Testes com Testing Library (unitários e de integração) e Cypress (ponta a ponta)

## Como rodar

Requisito: Node.js 16.

```bash
git clone https://github.com/IgorMarinhoArgollo/recipe-app.git
cd recipe-app
npm install
npm start
```

Outros scripts: `npm test`, `npm run cy` (Cypress), `npm run lint` e `npm run lint:styles`.
